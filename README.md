# OpenCode React Portfolio - Workshop Prompts

Welcome to the vibecoding workshop! Use the prompts below in sequence with OpenCode to build your React portfolio. 
Just copy and paste each prompt block when instructed.

## Prompt 1 — Initialize Project
```text
Create a new React project in this directory using Vite, Javascript, and Tailwind CSS.
Install all dependencies.
When done, stop.
```

## Prompt 2 — Build the Portfolio Design
```text
Create a one-page personal portfolio.
Do not add a navbar.
Use this design:
Light gray page background
Centered container with max width around 1200px
Large profile section at the top
White rounded cards
Thin gray borders
Soft shadows
Dark navy text
Green accent color
Clean modern typography
Generous spacing
At the top show:
Profile photo
Name
Location
Role
Email button
GitHub button
LinkedIn button
Below the profile, use a two-column layout.

Left column:
About
Experience
Projects
Right column:
Tech Stack
Education
Contact
Make the left column wider than the right.
Use placeholder content.
Make it look like a professional developer profile.
When done, stop.
```

## Prompt 5 — Improve the Visual Design
```text
Polish the current portfolio.
Use rounded cards around 16px.
Use subtle borders and shadows.
Improve typography and spacing.
Make section titles small, bold, and uppercase.
Use a small green dot beside section titles.
Add clean button hover effects.
Add subtle card hover effects.
Make the profile image rounded.
Keep the page minimal and professional.
Do not add a navbar.
Do not add extra pages.
Do not completely redesign the layout.
When done, stop.
```

## Prompt 6 — Responsive and Final Check
```text
Make the portfolio responsive.
Desktop:
Use the two-column layout.
Mobile:
Use one column.
Make the profile section stack properly on small screens.
Fix spacing and overflow.
Check all buttons and links.
Check light and dark mode.
Fix React, TypeScript, and Tailwind errors.
Do not add new features.
When done, stop.
```
